# Phase 4: 作品集页面 - 验收标准

## 验收概述

本文档定义 Phase 4 作品集页面的验收标准，确保功能完整、设计符合规范、性能达标。

---

## 1. 功能验收

### 1.1 页面访问

- [ ] 从首页点击"作品集"导航链接，可正常跳转到 `portfolio.html`
- [ ] 页面标题显示为"作品集 - 510"
- [ ] 导航栏"作品集"链接标记为激活状态（`.active`）

### 1.2 项目展示

- [ ] 至少展示 3 个项目卡片
- [ ] 每个卡片包含以下信息：
  - [ ] 项目名称（大标题，醒目）
  - [ ] 技术栈标签（胶囊样式，支持多标签）
  - [ ] 项目描述（1-2 句话）
  - [ ] 成果链接（可点击跳转）
- [ ] 卡片悬停时有视觉反馈（抬起效果 + 阴影加深）

### 1.3 导航与链接

- [ ] 项目卡片链接可正常跳转（GitHub 或项目地址）
- [ ] 外部链接在新标签页打开（`target="_blank"`）
- [ ] Footer 中的社交媒体链接正常工作

---

## 2. 设计验收

### 2.1 视觉风格

- [ ] 卡片采用杂志裁切风格（Esther Design System #1A）
- [ ] 标题使用 `Fraunces` 或 `Noto Serif SC` 衬线字体，字重 900/700
- [ ] 技术栈标签使用胶囊按钮样式，圆角、品牌配色
- [ ] 项目描述使用 `Noto Sans SC` 无衬线字体，易读性好

### 2.2 品牌配色

- [ ] 蓝色标签使用 `rgba(43, 127, 216, 0.12)` 背景 + `#2B7FD8` 文字
- [ ] 黄色标签使用 `rgba(244, 215, 88, 0.3)` 背景 + 深黄色文字
- [ ] 红色标签使用 `rgba(232, 74, 95, 0.12)` 背景 + `#E84A5F` 文字
- [ ] 卡片背景为白色（`var(--white)`）
- [ ] 标题使用墨色（`var(--ink)`）
- [ ] 描述使用浅墨色（`var(--ink-light)`）

### 2.3 布局与间距

- [ ] 桌面端（>768px）：2 列网格布局，卡片间距 40px
- [ ] 移动端（≤768px）：1 列布局，卡片间距 24px
- [ ] 页面标题区居中对齐

### 2.4 动画与交互

- [ ] Scroll Reveal 动画正常触发（页面首次加载时）
- [ ] 卡片悬停时平滑抬起（`transform: translateY(-4px)`）
- [ ] 支持 `prefers-reduced-motion: reduce`（禁用动画）

---

## 3. 响应式验收

### 3.1 桌面端（≥1200px）

- [ ] 项目网格显示 2 列
- [ ] 卡片宽度自适应，间距 40px

### 3.2 平板端（768px - 1199px）

- [ ] 项目网格显示 2 列
- [ ] 卡片间距适当缩小（32px）

### 3.3 移动端（≤767px）

- [ ] 项目网格显示 1 列
- [ ] 卡片间距 24px
- [ ] 导航栏适配移动端（汉堡菜单或简化显示）
- [ ] 页面标题和副标题字号适当缩小（使用 `clamp()`）

### 3.4 测试设备

- [ ] iPhone SE (375px)
- [ ] iPad (768px)
- [ ] MacBook Pro (1440px)
- [ ] 4K 显示器 (2560px)

---

## 4. 性能验收

### 4.1 加载性能

- [ ] 首屏加载时间 < 2 秒（在 Chrome DevTools Network 面板中测试）
- [ ] 字体使用 `preconnect` 预连接优化
- [ ] CSS 和 JS 文件正确加载，无 404 错误

### 4.2 运行时性能

- [ ] 卡片悬停动画流畅，无卡顿
- [ ] Scroll Reveal 动画流畅触发

### 4.3 浏览器兼容性

- [ ] Chrome（最新版本）
- [ ] Firefox（最新版本）
- [ ] Safari（最新版本）
- [ ] Edge（最新版本）

### 4.4 控制台检查

- [ ] 无 JavaScript 错误
- [ ] 无 CSS 加载失败
- [ ] 无字体加载失败

---

## 5. 代码质量验收

### 5.1 HTML

- [ ] 语义化标签使用正确（`<section>`, `<nav>`, `<footer>`）
- [ ] 所有图片包含 `alt` 属性
- [ ] 外部链接包含 `rel="noopener"` 或 `rel="noreferrer"`

### 5.2 CSS

- [ ] 使用 CSS 变量（`var(--blue)`, `var(--yellow)` 等）
- [ ] 媒体查询顺序正确（移动优先或桌面优先）
- [ ] 无冗余或未使用的样式
- [ ] 响应式单位使用 `clamp()` 或相对单位（`rem`, `%`, `vw`）

### 5.3 JavaScript

- [ ] 使用 ES6 模块（`type="module"`）
- [ ] 事件监听器正确绑定和解绑
- [ ] 无全局变量污染
- [ ] 代码逻辑清晰，易于维护

---

## 6. 可访问性验收

### 6.1 键盘导航

- [ ] 卡片链接可通过键盘访问
- [ ] Tab 键可正常切换焦点

### 6.2 语义化

- [ ] 项目卡片使用合适的标签结构（`<article>` 或 `<div>`）
- [ ] 页面标题使用 `<h1>`, 卡片标题使用 `<h3>`

### 6.3 对比度

- [ ] 文字与背景对比度符合 WCAG AA 标准（4.5:1）
- [ ] 链接颜色与周围文字有明显区分
