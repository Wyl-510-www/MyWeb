## 已解决问题

### P1 - Footer 堆叠卡片实现问题

**问题描述**：
Footer 区域的联系方式堆叠卡片（Stacked Cards）无法正确显示堆叠效果，两张卡片内容完全重叠，视觉效果异常。多次尝试修复未能解决。

**影响范围**：
- Footer 区域的联系方式展示
- 影响用户体验和视觉美观度

**尝试的修复方案**：
1. ✗ 移除内联事件处理器，改用 JS 事件委托
2. ✗ 移除 `.reveal` 类避免 transform 冲突
3. ✗ 在 JS 中显式初始化卡片状态
4. ✗ 使用 Esther Design System 官方实现
5. ✓ 最终方案：弃用堆叠卡片，改用编号卡片网格（Numbered Card Grid）

**最终解决方案**：
采用 Esther Design System 的编号卡片网格组件替代堆叠卡片：
- 2列网格布局（移动端自动单列）
- 使用 `data-num` 属性添加编号装饰
- 邮箱显示为纯文本信息
- 小红书显示为可点击链接
- hover 时卡片轻微上浮

**修改文件**：
- `index.html:125-136` - 使用编号卡片网格结构
- `components/footer/footer.css:35-66` - 编号卡片网格样式
- `components/footer/footer.js:1-3` - 清理堆叠卡片逻辑
