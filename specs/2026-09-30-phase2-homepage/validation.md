# Phase 2: 首页开发 - 验收标准

## 功能验收

### ✅ 1. 页面可访问性
- [ ] 在浏览器中打开 `index.html`，页面正常加载
- [ ] 无 JavaScript 错误（打开浏览器控制台检查）
- [ ] 所有图片资源正常显示（头像、图标）

### ✅ 2. Hero 区域
- [ ] 头像显示为圆形，尺寸合适
- [ ] 标题「记录 · 成长 · 分享」使用 Noto Serif SC 字体
- [ ] 标题颜色为主色蓝（`#2B7FD8`）
- [ ] 副标题和简介文字清晰可读
- [ ] 整体居中对齐

### ✅ 3. 导航卡片区域
- [ ] 四个卡片均正常显示（作品集、学习笔记、生活记录、关于我）

### ✅ 4. Footer 区域
- [ ] 显示邮箱和小红书两个联系方式
- [ ] 邮箱链接点击后打开邮件客户端

- [ ] 使用堆叠卡片样式，视觉层次清晰

## 响应式验收

### ✅ 5. 桌面视图（> 900px）
**测试分辨率**：1920px、1440px、1280px

- [ ] Hero 区域头像尺寸：120px × 120px

**测试分辨率**：768px、900px

- [ ] Hero 区域头像缩小至 100px × 100px
- [ ] 标题字号：36px
- [ ] 导航卡片：2 × 2 网格或 2 列布局
- [ ] Footer 水平或垂直排列（根据空间）

### ✅ 7. 手机视图（< 600px）
**测试分辨率**：375px、414px

- [ ] Hero 区域头像缩小至 80px × 80px

- [ ] 3D 翻转效果禁用或改为简单悬停样式（触摸设备）
- [ ] Footer 垂直堆叠

## 视觉验收

### ✅ 8. 品牌色使用
- [ ] 主色蓝（`#2B7FD8`）：标题、链接、导航卡片（学习笔记）
- [ ] 强调色黄（`#F4D758`）：装饰、导航卡片（生活记录）
- [ ] 点缀色红（`#E84A5F`）：CTA、导航卡片（作品集）
- [ ] 颜色比例符合 60% · 30% · 10% 原则

### ✅ 9. 字体渲染
- [ ] 中文标题使用 Noto Serif SC（衬线）
- [ ] 中文正文使用 Noto Sans SC（无衬线）
- [ ] 英文装饰（如有）使用 Fraunces（italic）
- [ ] 字体加载正常，无闪烁（FOIT/FOUT）

### ✅ 10. 间距与对齐
- [ ] 各区域间距一致（使用统一的 spacing 变量）
- [ ] 内容居中对齐或遵循设计系统的对齐规则
- [ ] 无内容溢出或错位

## 代码质量验收

- [ ] 使用 `<header>`、`<main>`、`<footer>` 等语义化标签

- [ ] 键盘可导航（Tab 键切换焦点）

- [ ] 支持屏幕阅读器（使用 NVDA 或 VoiceOver 测试）

## 验收测试步骤

### 自动化测试（可选）
```bash
# 使用 HTML 验证器
npx html-validate index.html

# 使用 CSS 验证器
npx stylelint "css/**/*.css"

# 运行 Lighthouse 性能测试
npx lighthouse http://localhost:8000 --view
```

### 手动测试清单

#### 桌面测试（Chrome DevTools）
1. 打开 `index.html`
2. 按 F12 打开开发者工具
3. 切换到 Responsive 模式
4. 依次测试 1920px、1440px、1280px、900px、768px、600px、414px、375px
5. 检查每个断点的布局和交互

#### 移动端真机测试
1. 将项目部署到本地服务器（`python -m http.server` 或 VS Code Live Server）
2. 使用手机访问本地 IP 地址
3. 测试触摸交互和滚动流畅度

#### 键盘导航测试
1. 使用 Tab 键遍历所有可交互元素
2. 确认焦点状态清晰可见
3. 使用 Enter/Space 触发链接和按钮

#### 屏幕阅读器测试
1. 启用 NVDA（Windows）或 VoiceOver（macOS）
2. 听取页面内容朗读
3. 确认标题、链接、图片描述清晰
