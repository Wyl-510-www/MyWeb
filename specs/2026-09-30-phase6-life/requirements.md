# Phase 6: 生活记录系统 - 需求文档

## 功能定位

建立个人生活档案系统，记录日常瞬间、思考感悟和生活随笔，与技术笔记形成互补，完整呈现个人成长的技术和生活两个维度。

## 核心目标

1. **真实记录**：捕捉生活瞬间、情感和思考
2. **视觉呈现**：支持多图展示，记录视觉化的生活片段
3. **轻松氛围**：与技术笔记区分，营造温暖轻松的阅读体验
4. **易于检索**：通过标签组织内容，方便回顾和查找

---

## 设计决策

### 1. 布局风格：时间线布局

**选择理由**：
- 强调时间流逝感，适合生活记录的线性叙事
- 每条记录带日期标记，清晰呈现生活轨迹
- 垂直滚动浏览，适合移动端阅读

**实现方式**：
- 列表页采用垂直时间线，左侧时间轴，右侧卡片内容
- 移动端简化为单列卡片 + 日期标签
- 按时间倒序排列（最新记录在最上方）

### 2. 图片展示：画廊模式多图

**选择理由**：
- 生活记录常包含多张照片（旅行、美食、活动）
- 横向滚动浏览，不破坏页面纵向流畅性
- 支持点击放大查看细节

**实现方式**：
- 每条记录支持 0-10 张图片
- 横向滚动画廊（`overflow-x: auto`）
- 点击图片触发 Lightbox 全屏查看
- 第一张图片作为卡片封面（缩略图）

### 3. 内容组织：标签筛选

**选择理由**：
- 生活内容多样化，固定分类难以覆盖
- 标签灵活可扩展（#旅行 #美食 #读书 #思考）
- 与笔记系统保持交互一致性

**实现方式**：
- 每条记录支持多标签（frontmatter `tags` 字段）
- 列表页顶部显示所有标签，支持点击筛选
- URL 参数支持：`life.html?tag=旅行`
- 复用笔记系统的标签筛选 JS 逻辑

### 4. 视觉风格：轻松温暖

**与笔记系统的差异**：
- **字体**：增加手写字体 Caveat 用于日期标签和装饰文字
- **配色**：增加暖色调（黄色强调色比例提升）
- **组件**：使用对话气泡、引用块、圆角卡片
- **装饰**：添加虚线边框、小图标（☀️📷✈️ 等）

## 技术实现

### 1. 复用笔记系统架构

- **Markdown 渲染**：复用 `marked` 库和配置
- **构建脚本**：参考 `scripts/build-notes.js`，调整路径和字段
- **标签筛选**：复用 `scripts/notes-filter.js` 逻辑
- **样式基础**：继承 Esther Design System 品牌色和字体

### 2. 新增功能

- **时间线布局**：新建 `css/life.css`，实现垂直时间轴
- **画廊组件**：新建 `scripts/image-gallery.js`，处理图片滚动和 Lightbox
- **手写字体**：在详情页标题和日期使用 Caveat 字体
- **对话气泡**：从 `components.md` 提取样式，封装为可复用 CSS 类

### 3. 性能优化

- **图片懒加载**：使用 `loading="lazy"` 属性 + Intersection Observer
- **缩略图**：列表页显示压缩版图片（需手动准备或使用构建脚本生成）
- **按需加载**：Lightbox 模态框 JS 仅在详情页加载

---

## 约束条件

1. **纯静态方案**：无需后端，所有内容通过 Markdown 文件管理
2. **响应式优先**：移动端体验与桌面端同等重要
3. **浏览器兼容性**：支持 Chrome/Edge/Safari/Firefox 最新两个版本
4. **无构建工具**：HTML/CSS/JS 直接运行，仅 Node.js 脚本预渲染 Markdown
