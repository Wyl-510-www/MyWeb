## 3. 性能验证

### 3.1 页面加载速度

**测试工具**：Chrome Lighthouse

**最低标准**：
- ✅ Performance 评分 ≥ 80
- ✅ Accessibility 评分 ≥ 90
- ✅ Best Practices 评分 ≥ 90
- ✅ SEO 评分 ≥ 85

**关键指标**：
- First Contentful Paint (FCP) < 2s
- Largest Contentful Paint (LCP) < 3s
- Cumulative Layout Shift (CLS) < 0.1

### 3.2 图片优化

**验证项**：
- ✅ 列表页缩略图尺寸 ≤ 300KB
- ✅ 详情页大图尺寸 ≤ 1MB
- ✅ 图片使用现代格式（WebP 或 JPEG）
- ✅ 所有图片添加 `loading="lazy"` 属性

### 3.3 交互流畅度

**测试场景**：
1. 快速滚动列表页
2. 连续切换标签筛选
3. 快速打开/关闭 Lightbox
4. 快速切换 Lightbox 图片

**预期结果**：
- ✅ 无明显卡顿
- ✅ 动画帧率稳定（接近 60fps）
- ✅ 无内存泄漏（长时间使用后性能不下降）

## 问题排查指南

### 问题 1：图片无法显示
**可能原因**：
- 图片路径错误（相对路径 vs 绝对路径）
- 图片文件未提交到 Git
- 构建脚本未正确处理图片路径

**解决方案**：
- 检查 `life-data.json` 中的图片路径
- 确认 `assets/images/life/` 目录结构正确
- 使用浏览器开发者工具查看 404 请求

### 问题 2：标签筛选不工作
**可能原因**：
- `life-data.json` 未加载成功
- JavaScript 文件未正确引入
- 标签名大小写不匹配

**解决方案**：
- 检查控制台错误信息
- 确认 `life-filter.js` 正确引入
- 调试 `fetch('life-data.json')` 请求

### 问题 3：Lightbox 无法关闭
**可能原因**：
- 事件监听器未正确绑定
- 键盘事件冲突
- 遮罩层 z-index 过低

**解决方案**：
- 检查 `image-gallery.js` 中的事件绑定
- 测试 `console.log()` 确认事件触发
- 调整 Lightbox CSS `z-index` 为 9999
