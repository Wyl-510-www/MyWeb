# Phase 3: 关于我页面 - 需求文档

## 功能范围

创建个人介绍页面 `about.html`，展示个人背景、技能和联系方式。

## 核心需求

### 1. 个人简介区域
- **详细自我介绍**：包含姓名、职业定位、个人背景
- **教育背景**：学习经历和专业方向
- **当前状态**：正在做什么、学什么、关注什么

### 2. 技能展示
- **能力象限分类**：
  - 开发能力（前端/后端技术栈）
  - 设计能力（UI/UX、视觉设计）
  - 学习能力（正在学习的技术）
  - 其他能力（软技能、工具使用）
- **使用 Esther Design System 图标卡片组件**

### 3. 联系方式
- GitHub 链接
- 邮箱地址
- 个人博客链接
- 社交媒体账号（微博/Twitter/LinkedIn）

### 4. 布局风格
- **卡片网格布局**：使用杂志卡片/票据样式等多种卡片组合
- **响应式**：桌面端多列，移动端单列
- **视觉层次**：使用 Esther Design System 的高亮、标题样式突出重点

## 设计决策

### 为什么选择卡片网格？
- 符合 Phase 2 首页的模块化设计风格
- 信息模块化，便于维护和更新
- 视觉丰富，避免大段文字的单调感
- 响应式友好，移动端自动堆叠

### 为什么用能力象限？
- 比单纯的技术标签更全面，展示综合能力
- 符合使命文档的"真实性"定位，展示成长过程
- 将"正在学习"作为独立维度，体现学习态度

### 为什么包含多渠道联系方式？
- 扩大影响力和可发现性
- 适应不同场景（技术交流、职业发展、社交互动）
- 建立个人品牌的多平台存在

## 技术上下文

### 复用的组件（来自 esther-design-system）
- **卡片组件**：
  - 杂志卡片（Magazine Card）- 用于简介区域
  - 图标卡片（Icon Card）- 用于能力象限
  - 票据样式（Ticket Style）- 用于联系方式
- **高亮样式**：
  - 黄色荧光笔（Yellow Highlighter）- 强调关键信息
  - 圆圈标记（Circle Mark）- 标注重点
- **按钮**：
  - 蓝色按钮（Blue Button）- 主要 CTA
  - 描边按钮（Outline Button）- 次要操作
- **标题样式**：
  - 阴影标题（Shadow Heading）
  - 大引号样式（Big Quote）- 个人 Slogan

### 导航集成
- 从首页导航卡片链接到 `about.html`
- 在 `about.html` 顶部保持导航栏一致性

### 品牌色应用
- 主色蓝 (`#2B7FD8`)：标题、图标
- 强调色黄 (`#F4D758`)：高亮、装饰
- 点缀色红 (`#E84A5F`)：CTA 按钮

## 约束条件

### 技术约束
- 纯静态 HTML/CSS，无构建步骤
- 复用 `css/variables.css` 中的品牌色变量
- 不引入新的外部依赖

### 设计约束
- 必须符合 Esther Design System 的组件规范
- 与首页视觉风格保持一致
- 移动端必须完全可用

### 内容约束
- 个人信息需真实准确
- 技能展示需客观，区分"已掌握"和"正在学习"
- 联系方式需有效可用

## 成功标准

1. **功能完整性**：所有必需信息区域都已实现
2. **响应式**：桌面端和移动端均正常显示
3. **风格一致性**：与首页视觉风格协调统一
4. **可维护性**：内容更新方便，结构清晰
5. **质量达标**：通过 `esther-design-system-main/references/checklist.md` P0 检查
