# Phase 7: 关于我页面 - 需求文档

## 功能范围

创建个人介绍页面 `about.html`，平衡展示**专业技术能力**与**个人特色**，传达真实、开放的个人品牌形象。

---

## 核心定位

**个人品牌风格**：在展示专业能力的同时，融入个人价值观、学习态度和生活兴趣，避免纯技术简历式的冷感，也避免过度生活化的随意感。

**目标受众**：
- 潜在雇主/合作者：了解技术背景和工作能力
- 同行开发者：感受学习态度和交流意愿
- 自己：记录当前阶段的自我认知

---

## 页面结构

### 1. 头部区域
- **头像展示**（`assets/avatar.jpg`）
- **标题**：姓名或昵称
- **副标题**：一句话身份标签（如"前端开发者 · 终身学习者"）

### 2. 个人简介区域
内容侧重点（按优先级）：
1. **职业身份与技术背景**
   - 当前职位/身份
   - 主要技术栈
   - 工作/学习年限
   
2. **学习态度与成长理念**
   - 学习方法和习惯
   - 对技术的追求和思考
   - 个人成长的记录意义（呼应 mission.md 的"真实记录成长"）
   
3. **兴趣爱好与生活态度**
   - 技术之外的兴趣
   - 生活方式和个人特色
   - 让读者感受到"人"而非"简历"

**呈现方式**：
- 使用 **大引号样式** 引用个人 slogan 或核心理念
- 使用 **黄色荧光笔高亮** 标记重点关键词
- 文字排版清晰，段落适中（移动端友好）

### 3. 技能展示区域
**混合展示方式**：
- **核心技能**：使用 **图标卡片**（Icon Card）展示 3-5 项核心技能
  - 每张卡片包含：图标、技能名称、简短描述或熟练度说明
  - 网格布局（桌面 3 列 / 移动 1-2 列）
  
- **其他技能**：使用 **胶囊标签**（Capsule Button）分组列出
  - 按类别分组：前端技术 / 后端技术 / 工具与方法
  - 彩色标签（蓝/黄/红三色系统）
  - 轻量展示，不占主视觉焦点

### 4. 联系方式区域
- **邮箱**：显示邮箱地址，支持点击复制或 mailto 链接
- **社交媒体链接**：
  - GitHub（必选）
  - 微信/QQ（可选，二维码或号码）
  - 知乎/掘金/博客（可选）
  - 最多展示 3-5 个平台
  - 使用图标 + 文字链接，悬停效果
  
- **CTA 按钮**：
  - "联系我" 蓝色按钮（跳转邮件或显示联系方式）
  - 可选："查看简历" 按钮（如果有 PDF 简历）

## 设计组件选择

从 `esther-design-system-main/references/components.md` 选择：

| 组件类型 | 组件名称 | 用途 |
|---------|---------|------|
| 引用样式 | **大引号样式（Big Pullquote）** | 引用个人 slogan 或核心理念 |
| 高亮标记 | **黄色荧光笔（Yellow Highlighter）** | 高亮简介中的关键词 |
| 卡片 | **图标卡片（Icon Card）** | 展示核心技能（3-5 项） |
| 按钮 | **胶囊按钮（Capsule Button）** | 其他技能标签（分组展示） |
| 按钮 | **蓝色按钮（Blue Button）** | 主 CTA"联系我" |
| 按钮 | **描边按钮（Outline Button）** | 次要 CTA"查看简历"（可选） |

**不使用的组件**：
- 对话气泡、手写注释、打字机效果（偏生活化，不符合此页面的专业平衡定位）
- 杂志裁切卡片（已用于作品集，避免重复）

---

## 布局与响应式

**页面布局**：
- **垂直单列布局**（移动优先）
- 区块顺序：导航栏 → 头像+标题 → 简介 → 技能 → 联系方式 → Footer
- 桌面端保持单列，通过卡片网格优化视觉密度

**响应式断点**：
- 桌面端（≥768px）：
  - 技能卡片 3 列网格
  - 简介文字适当加宽（最大宽度 800px）
- 移动端（<768px）：
  - 技能卡片 1-2 列
  - 文字全宽，间距优化

## 技术实现

### 文件结构
```
MyWeb/
├── about.html                    # 关于我页面
├── components/
│   └── skill-card.js             # 技能卡片组件（新增）
├── css/
│   └── about.css                 # 关于我页面样式
└── assets/
    └── avatar.jpg                # 头像（已存在）
```

### 技术栈
- 纯 HTML/CSS + 原生 JavaScript
- ES6 模块化（复用现有导航栏和 Footer 组件）
- 响应式设计（复用品牌色变量 `css/variables.css`）
- Scroll Reveal 动画（可选，与首页保持一致）

### 数据源
- **个人信息**：硬编码在 HTML 中（姓名、头像、简介文字）
- **技能列表**：可选方案：
  - 方案 A：硬编码在 HTML（简单直接）
  - 方案 B：创建 `data/skills.json`，JavaScript 动态渲染（便于后续更新）
  - **推荐**：方案 A（当前阶段技能相对固定，无需动态化）

  - 兴趣爱好与生活态度

## 边界与约束

### 包含
- 个人简介、技能展示、联系方式
- 响应式布局（桌面 + 移动端）
- 使用 Esther Design System 组件
- 保持品牌视觉一致性

### 不包含
- 时间线展示（过于复杂，不符合"简洁"原则）
- 技能进度条动画（视觉噪音，缺乏实际信息价值）
- 在线状态/时区提示（当前阶段无需此功能）
- 简历下载按钮（除非用户明确提供 PDF 简历）
- 评论或留言功能（Phase 8+ 扩展功能）

### 性能要求
- 页面加载时间 <2 秒
- 图片优化（头像压缩到 500KB 以内）
- 移动端交互流畅（无卡顿）

---

## 成功标准

1. **内容完整性**：简介、技能、联系方式三大区块清晰呈现
2. **视觉一致性**：使用 Esther Design System，与首页/作品集风格统一
3. **响应式适配**：桌面端和移动端均排版合理、易读
4. **信息层次**：核心技能突出，其他技能次要，联系方式明确
5. **品牌传达**：读者能感受到"平衡专业与个性"的定位
