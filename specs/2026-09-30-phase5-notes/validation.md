# Phase 5: 学习笔记系统 - 验证标准

## 功能验证清单

### 1. 构建脚本验证
- [ ] **脚本执行成功**：运行 `node scripts/build-notes.js` 无报错
- [ ] **生成文件正确**：
  - `notes/` 目录下生成对应的 HTML 文件（如 `javascript-performance.html`）
  - 生成 `notes-data.json` 包含所有笔记元数据
- [ ] **元数据解析正确**：
  - title、date、tags、description、readingTime 正确提取
  - 中文标题和标签正确处理（UTF-8 编码）
- [ ] **HTML 内容正确**：
  - Markdown 转换为 HTML 标签正确
  - 代码块被包装在 Mac 窗口样式中
  - 引用块应用重点笔记样式

---

### 2. 笔记列表页验证

#### 2.1 页面结构
- [ ] **导航栏显示**：复用全站导航组件，链接正确
- [ ] **页面标题**：大标题"学习笔记"显示正确
- [ ] **标签筛选器**：显示所有唯一标签（无重复）
- [ ] **笔记卡片网格**：所有笔记卡片正确渲染
- [ ] **Footer 显示**：复用全站 Footer，样式正确

#### 2.2 笔记卡片内容
每个卡片必须包含：
- [ ] **标题**：使用 Fraunces 900 字体，字号足够大
- [ ] **标签**：胶囊按钮样式，蓝/黄/红三色交替
- [ ] **发布时间**：格式为"2026-09-30"，小字灰色
- [ ] **摘要**：1-2 行简介，Noto Sans SC 字体
- [ ] **阅读时长**：显示"X 分钟阅读"
- [ ] **阅读链接**：链接可点击，跳转到详情页

#### 2.3 标签筛选功能
- [ ] **初始状态**：显示所有笔记
- [ ] **点击标签**：
  - 只显示包含该标签的笔记
  - 选中的标签高亮（不同背景色或边框）
  - 其他卡片隐藏（`display: none` 或淡出动画）
- [ ] **取消筛选**：
  - 点击"全部"或再次点击选中的标签
  - 恢复显示所有笔记
- [ ] **URL 参数支持**：
  - 访问 `notes.html?tag=JavaScript` 自动筛选
  - 筛选后刷新页面，筛选状态保持

#### 2.4 响应式布局
- [ ] **桌面（> 1024px）**：3 列网格，间距合理
- [ ] **平板（768px - 1024px）**：2 列网格
- [ ] **移动（< 768px）**：1 列堆叠，卡片宽度 100%
- [ ] **卡片悬停效果**：桌面端悬停时抬升 + 阴影增强

---

### 3. 笔记详情页验证

#### 3.1 页面结构
- [ ] **导航栏显示**：复用全站导航组件
- [ ] **阅读进度条**：固定在页面顶部，初始宽度为 0
- [ ] **文章头部**：
  - 标题使用阴影标题或穿透标题样式
  - 发布时间和标签显示正确
  - 阅读时长显示
- [ ] **文章正文**：Markdown 内容正确渲染
- [ ] **返回导航**：底部显示"返回笔记列表"链接
- [ ] **Footer 显示**：复用全站 Footer

#### 3.2 内容样式
- [ ] **标题样式**（h1-h6）：使用阴影标题或自定义样式
- [ ] **段落**：Noto Sans SC 字体，行高 1.8，字号 16-18px
- [ ] **链接**：蓝色 + 波浪下划线，悬停动画
- [ ] **列表**：自定义 bullet 点或编号样式
- [ ] **代码块**：
  - 使用 Mac 窗口样式（红黄绿按钮）
  - 代码高亮（如有）
  - 横向滚动支持（长代码不溢出）
- [ ] **引用块**：重点笔记样式（大引号，黄色背景或边框）
- [ ] **图片**（如有）：响应式，最大宽度 100%

#### 3.3 阅读进度条功能
- [ ] **初始状态**：页面顶部显示，宽度为 0
- [ ] **滚动更新**：
  - 向下滚动时，进度条宽度增加
  - 滚动到底部时，进度条接近 100%
  - 计算公式正确：`progress = (scrollTop / (scrollHeight - clientHeight)) * 100`
- [ ] **样式**：
  - 固定定位（`position: fixed; top: 0`）
  - 蓝色渐变或纯蓝色
  - 高度 3-5px
  - z-index 足够高（覆盖其他内容）

#### 3.4 返回导航
- [ ] **链接显示**：文章底部，蓝色按钮样式
- [ ] **图标**（可选）：向左箭头 `←`
- [ ] **点击跳转**：返回 `notes.html`，保持筛选状态（如有）

### 7. Esther Design System 检查清单

对照 `esther-design-system-main/references/checklist.md` P0 检查项：

#### 7.1 可访问性
- [ ] **颜色对比度**：文字与背景对比度 ≥ 4.5:1（WCAG AA 标准）
- [ ] **可点击区域**：按钮和链接点击区域 ≥ 44x44px（移动端）
- [ ] **键盘导航**（可选）：Tab 键可导航到所有交互元素

#### 7.2 响应式设计
- [ ] **断点正确**：
  - 移动端：< 768px
  - 平板：768px - 1024px
  - 桌面：> 1024px
- [ ] **字体缩放**：移动端字体自动缩小（不小于 14px）
- [ ] **间距适配**：移动端 padding/margin 减半

#### 7.3 组件复用
- [ ] **禁止自创样式**：所有组件从 Esther Design System 选择
- [ ] **品牌色使用正确**：
  - 主色（蓝）60%
  - 强调色（黄）30%
  - 点缀色（红）10%
- [ ] **字体使用正确**：
  - 中文标题：Noto Serif SC
  - 中文正文：Noto Sans SC
  - 英文装饰：Fraunces
  - 代码：Fira Code
