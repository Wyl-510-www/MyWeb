# Phase 5: 学习笔记系统 - 需求文档

## 功能范围

### 核心目标
实现支持 Markdown 笔记展示和浏览的学习笔记系统，让用户能够记录和展示技术学习过程、踩坑经验、知识总结。

### 已确认的技术决策

#### 1. Markdown 渲染方案：Node.js 预渲染
- **方案**：使用 Node.js 脚本在构建时将 `.md` 文件转换为 HTML
- **优势**：
  - 纯静态文件部署，性能最优
  - 无需在浏览器端加载 marked.js 等解析库
  - 符合项目"纯静态 HTML/CSS"的技术栈定位
- **实施方式**：
  - 编写 `build-notes.js` 脚本
  - 读取 `content/notes/*.md` 文件
  - 使用 `marked.js` 转换为 HTML
  - 套用 Esther Design System 样式
  - 生成静态 HTML 页面到 `notes/` 目录

#### 2. 笔记列表页面布局：卡片网格
- **方案**：使用杂志裁切风格卡片组件
- **布局规则**：
  - 桌面端：2-3 列网格
  - 移动端：1 列堆叠
- **卡片内容**：
  - 笔记标题（大标题，Fraunces 900）
  - 标签（胶囊按钮样式）
  - 发布时间
  - 摘要（1-2 句简介）
  - 阅读时长估算

#### 3. 笔记分类和组织方式
**已选择**：标签系统 + 时间排序

- **标签系统**：
  - 每篇笔记支持多标签（如：JavaScript、React、性能优化）
  - 标签使用胶囊按钮样式（蓝/黄/红三色）
  - 支持按标签筛选笔记列表
  
- **时间排序**：
  - 默认按发布时间倒序展示
  - 在卡片上显示发布日期

#### 4. 功能优先级
本阶段实现：
- ✅ **笔记列表 + 详情页**（核心功能）
- ✅ **标签筛选**（点击标签过滤列表）
- ✅ **阅读进度条**（详情页顶部显示）
- ✅ **Mac 窗口代码样式**（代码块使用 macOS 窗口风格）
- ✅ **查看源文件链接**（跳转到 GitHub 查看 Markdown 源文件）

暂不实现：
- ❌ 全文搜索（留待 Phase 8+ 扩展）
- ❌ 系列专题（当前阶段不需要）
- ❌ 目录分类（标签系统已足够）
- ❌ 在线编辑功能（与纯静态定位冲突）
- ❌ PDF 导出（技术复杂度高）

## 页面结构

### 1. 笔记列表页 (`notes.html`)
- **导航栏**：复用全站导航组件
- **页面标题**：大标题 "学习笔记"
- **标签筛选器**：所有标签的胶囊按钮，支持点击筛选
- **笔记卡片网格**：
  - 杂志裁切风格卡片
  - 桌面 2-3 列，移动端 1 列
  - 每个卡片包含：标题、标签、时间、摘要、阅读链接
- **Footer**：复用全站 Footer 组件

### 2. 笔记详情页 (`notes/[slug].html`)
- **导航栏**：复用全站导航组件
- **阅读进度条**：固定在页面顶部
- **文章头部**：
  - 标题（穿透标题样式或阴影标题）
  - 发布时间
  - 标签列表
  - 阅读时长
  - **查看源文件链接**：跳转到 GitHub 对应的 .md 源文件
- **文章正文**：
  - Markdown 渲染内容
  - 代码块使用 Mac 窗口样式
  - 引用块使用重点笔记样式
  - 标题使用阴影标题样式
- **返回导航**：返回笔记列表的链接
- **Footer**：复用全站 Footer 组件

## 技术实施细节

### Markdown 元数据
每篇笔记的 `.md` 文件需包含 YAML front matter：

```yaml
---
title: 笔记标题
date: 2026-09-30
tags: [JavaScript, React, 性能优化]
description: 一句话简介，用于卡片摘要
readingTime: 5 分钟
---
```

### 构建脚本职责
`build-notes.js` 需要：
1. 扫描 `content/notes/*.md` 文件
2. 解析 YAML front matter
3. 使用 `marked.js` 转换 Markdown 为 HTML
4. 生成笔记详情页 HTML（套用 Esther Design System 样式）
5. 生成笔记列表数据 JSON（供 `notes.html` 读取）
6. 输出到 `notes/` 目录

### 标签筛选实现
- 使用原生 JavaScript
- 点击标签时，通过 CSS 类控制卡片显示/隐藏
- URL 参数支持（如 `notes.html?tag=JavaScript`）

### 阅读进度条实现
- 使用原生 JavaScript 监听滚动事件
- 计算阅读进度百分比
- 更新顶部进度条宽度

## 设计规范

### 颜色使用
- **主色（蓝 #2B7FD8）**：链接、标题、主要按钮
- **强调色（黄 #F4D758）**：标签装饰、高亮
- **点缀色（红 #E84A5F）**：CTA 按钮、重要标签

### 组件复用
从 Esther Design System 选择：
- **卡片**：杂志裁切卡片（笔记列表）
- **按钮**：胶囊按钮（标签）
- **代码块**：Mac 窗口样式
- **引用块**：重点笔记样式
- **标题**：阴影标题或穿透标题
- **高亮**：黄色荧光笔
