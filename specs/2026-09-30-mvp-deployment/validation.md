# MVP 验证清单

本文档定义了 MVP 部署成功的验证标准和详细测试清单。

---

## 验证维度

MVP 必须通过以下 4 个维度的验证：

1. ✅ **响应式布局正常**
2. ✅ **导航和链接完整可用**
3. ✅ **性能达标**
4. ✅ **内容完整无占位符**

## 3. 性能达标

### 3.1 Lighthouse 测试

#### 测试页面
对以下页面分别运行 Lighthouse 测试：
- [ ] 首页 (index.html)
- [ ] 作品集页面 (portfolio.html)
- [ ] 学习笔记列表页 (notes.html)
- [ ] 学习笔记详情页（选择 1 篇笔记）
- [ ] 生活记录列表页 (life.html)
- [ ] 关于我页面 (about.html)

#### 测试条件
- 使用 Chrome DevTools 的 Lighthouse 工具
- 选择「桌面」模式测试桌面端性能
- 选择「移动」模式测试移动端性能
- 清除缓存后测试

#### 性能指标要求

| 指标 | 目标值 | 备注 |
|------|--------|------|
| Performance Score | > 90 | Lighthouse 综合性能评分 |
| LCP (Largest Contentful Paint) | < 2.5s | 最大内容绘制时间 |
| CLS (Cumulative Layout Shift) | < 0.1 | 累积布局偏移 |
| FID (First Input Delay) | < 100ms | 首次输入延迟 |
| TTI (Time to Interactive) | < 3.8s | 可交互时间 |

### 3.2 性能优化检查

如果性能测试不达标，检查以下优化项：

#### 图片优化
- [ ] 所有图片已压缩
- [ ] 图片已转换为 WebP 格式
- [ ] 头像文件大小 < 100KB
- [ ] 生活记录中的图片已优化
- [ ] 图片有明确的 `width` 和 `height` 属性（防止 CLS）

#### CSS 优化
- [ ] CSS 文件已压缩（可选）
- [ ] 移除未使用的 CSS（可选）
- [ ] 关键 CSS 内联（可选）

#### JavaScript 优化
- [ ] JavaScript 文件已压缩（可选）
- [ ] 使用 `defer` 或 `async` 加载非关键脚本

#### 字体优化
- [ ] 字体使用 `font-display: swap`
- [ ] 字体文件压缩（可选）

#### 资源加载优化
- [ ] 使用 `<link rel="preload">` 预加载关键资源（可选）
- [ ] 使用 `<link rel="prefetch">` 预加载下一页资源（可选）

## 验证通过标准

## 验证失败处理

如果某项验证失败，需要：

1. **记录问题**：在 `specs/2026-09-30-mvp-deployment/issues.md` 中记录问题详情
2. **评估严重程度**：
   - **严重问题**（阻碍上线）：必须立即修复
   - **中等问题**（影响体验）：尽快修复
   - **轻微问题**（不影响功能）：可以记录在 TODO.md 中，上线后修复
3. **修复问题**：根据优先级修复问题
4. **重新验证**：修复后重新运行相应的验证清单
