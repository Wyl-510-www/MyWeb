# MyWeb 技术栈

## 核心决策：复用 Esther Design System

参考网站作者开源了完整的设计系统，包含 51 个组件、16 种布局模式和完整的品牌规范。**直接复用该系统，而非从零搭建 Vue 项目。**

### 为什么选择这个方案？

1. **即拿即用**：纯 HTML/CSS，无需构建工具，开发效率最高
2. **设计完整**：品牌色、字体、间距、响应式规则已定义
3. **质量保证**：51 个经过验证的组件，16 种布局模式
4. **符合需求**：参考网站本身就是用这套系统构建的

---

## 技术架构

### 前端技术
**纯静态 HTML/CSS + 原生 JavaScript**

- **无需框架**：直接使用 Esther Design System 的模板和组件
- **无构建步骤**：浏览器直接打开即可预览
- **快速迭代**：修改 HTML 立即生效

### 设计系统资源

已下载到项目目录：`esther-design-system-main/`

#### 核心文件
```
esther-design-system-main/
├── brand-dna.md              # 品牌基因（颜色/字体/气质）
├── assets/
│   ├── template-*.html       # 4 种场景模板
│   └── avatar.jpg            # 需替换为自己的头像
└── references/
    ├── components.md         # 51 个组件库
    ├── layouts.md            # 16 种布局模式
    └── checklist.md          # 质量检查清单
```

#### 可用组件分类（51 个）
1. **文字特效**：闪烁星星、形变文字、打字机效果、动态文字、漫画文字、旋转文字
2. **按钮**：蓝色按钮、黄色按钮、描边按钮、胶囊按钮
3. **卡片**（多种风格）：
   - 杂志卡片、数字卡片、标签卡片、图标卡片
   - 大数字卡片、虚线边框卡片、渐变卡片、排版卡片
   - 书籍卡片、票据样式、酒店样式、翻转卡片
4. **布局组件**：网格布局、悬浮揭示卡片、数字网格
5. **代码展示**：Mac 窗口、笔记本风格、打字机风格、简洁风格
6. **对话气泡**、**打字机区块**、**报纸排版**
7. **标题样式**：阴影标题、穿透标题
8. **高亮**：黄色荧光笔、波浪下划线、圆圈标记、方框标记
9. **引用块**：重点笔记、大引号样式

### 品牌色系（可定制）

| 颜色 | 色值 | 用途 |
|------|------|------|
| 蓝（主色） | `#2B7FD8` | 标题、链接、重点标记 |
| 黄（强调色） | `#F4D758` | 装饰、badges、高亮 |
| 红（点缀色） | `#E84A5F` | CTA、标签 |

比例原则：主色 60% · 强调色 30% · 点缀色 10%

### 字体方案

| 用途 | 字体 |
|------|------|
| 中文标题 | Noto Serif SC (衬线) |
| 中文正文 | Noto Sans SC (无衬线) |
| 英文装饰 | Fraunces (italic) |
| 手写注释 | Caveat |
| 代码/终端 | Fira Code |

### Markdown 渲染（笔记系统）

**方案一：纯静态预渲染**（推荐）
- 使用 Node.js 脚本将 Markdown 文件转换为 HTML
- 套用 Esther Design System 的样式
- 构建时生成，无需前端运行时解析

**方案二：客户端渲染**
- 使用 `marked.js` 或 `markdown-it`
- 搭配 Prism.js 代码高亮
- 适用于需要动态加载笔记的场景

### 部署方案

**GitHub Pages**（推荐）
- 免费托管静态网站
- 自动 HTTPS
- 与 GitHub 仓库无缝集成
- 支持自定义域名

## 优势

- ✅ **零配置**：无需 npm、webpack、Vite 等构建工具
- ✅ **高质量**：设计系统经过验证，有完整的 checklist
- ✅ **响应式**：所有组件原生支持移动端
- ✅ **可定制**：品牌色、字体可替换
- ✅ **快速开发**：直接复用模板和组件，无需从零设计

## 后续扩展

如果项目复杂度增加，需要以下功能时可考虑迁移到框架：
- 复杂的状态管理
- 大量动态内容加载
- 需要 SSR/SSG 优化 SEO
- 需要集成后端 API

届时可迁移到 **Vue 3 + Vite** 或 **Nuxt 3**，并将 Esther Design System 的 CSS 提取为独立样式库。
